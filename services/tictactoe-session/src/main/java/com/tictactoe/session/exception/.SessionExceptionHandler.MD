# SessionExceptionHandler

The session service's single `@RestControllerAdvice`, per the project's "one advice per service" rule. Currently adds no session-specific overrides: session-specific exceptions such as `SessionNotFoundException` and `SimulationAlreadyRunningException` already extend the shared `com.tictactoe.common.error.BaseException`, so they're fully handled by the inherited `handleBaseException` in `BaseGlobalExceptionHandler`, which builds the standard `{timestamp, status, code, message, path}` error body from the exception's `ErrorCode`.

## Key Components

- `@RestControllerAdvice` - Registers this class as the exception-handling advice for every controller in the session service.
- Extends `BaseGlobalExceptionHandler` - Inherits the shared exception-to-`ErrorResponse` mapping logic (validation errors, `BaseException` subclasses, generic fallbacks) from `tictactoe-common`, ensuring the session service's error responses have the identical shape to the engine's.

## Usage Example

```java
throw new SessionNotFoundException(ErrorCode.SESSION_NOT_FOUND, "Session " + sessionId + " does not exist");
```

Any code in the session service that throws this (or `SimulationAlreadyRunningException`, or any other `BaseException` subclass) is automatically caught by the inherited handler and turned into the correct HTTP status and JSON error body — no additional code needed in this class.
