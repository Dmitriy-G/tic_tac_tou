# GameEngineClient

Interface for the session service's HTTP client to the Game Engine Service. Defines the two engine operations the session service needs — starting a game and applying a move — in terms of the shared `tictactoe-common` wire DTOs, keeping the session service's callers (session lifecycle/simulation code) decoupled from the concrete HTTP implementation (`GameEngineClientImpl`) so it can be swapped for a test double or mock in unit tests.

## Key Components

- `createGame(String gameId)` - Requests a new game from the engine for the given `gameId`, returning the engine's `CreateGameResponse` (board, status, next symbol).
- `move(String gameId, String player, int position)` - Submits a move for `player` at `position` on `gameId`, returning the engine's authoritative `MoveResponse` (board, status, next symbol, winner, winning line).

## Usage Example

```java
public class SessionService {
    private final GameEngineClient engineClient;

    void applyMove(String gameId, String symbol, int position) {
        MoveResponse response = engineClient.move(gameId, symbol, position);
    }
}
```

The session service depends on this interface rather than `GameEngineClientImpl` directly, letting simulation tests substitute a mock `GameEngineClient` without standing up an HTTP server.
