# SimulationConfig

Spring configuration class that provides the single, shared `Random` bean used throughout the simulation code. Exists so that no strategy or service ever calls `new Random()` inline — a project anti-pattern that would make tests non-deterministic — and so tests can supply a seeded `Random` instead of this bean when they need reproducible move sequences.

## Key Components

- `@Configuration` - Marks this class as a source of Spring bean definitions.
- `@Bean random()` - Produces the single `Random` instance injected into `MoveStrategyResolver` and, transitively, into `RandomMoveStrategy`.

## Usage Example

```java
public MoveStrategyResolver(Random random, ...) {
    this.strategiesBySymbol = Map.of("X", new RandomMoveStrategy(random), ...);
}
```

Spring injects the single `Random` bean defined here into any component that declares a `Random` constructor parameter, such as `MoveStrategyResolver`; a test context can override this bean with a seeded `Random` to make move selection deterministic.
