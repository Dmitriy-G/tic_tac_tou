# MoveRecord

A single entry in a session's move log, as returned in `SessionResponse.moves`. Captures everything the frontend's move log needs to render one row: which move number it was, which symbol played it, where, and the resulting step status — without exposing any engine-internal or persistence details.

## Key Components

- `moveNumber` - 1-based index of this move within the game, used for the move-numbered log the frontend renders.
- `symbol` - The shared `Symbol` enum value (`X` or `O`) that made this move.
- `position` - The board cell played, `0..8` row-major, matching the engine's move contract.
- `stepStatus` - The shared `StepStatus` enum value describing the outcome of this specific step (e.g. in-progress, won, drawn).

## Usage Example

```java
List<MoveRecord> moves = List.of(new MoveRecord(1, Symbol.X, 4, StepStatus.IN_PROGRESS));
```

`SessionService` accumulates one `MoveRecord` per move made during a simulation and returns the full list as part of `SessionResponse`, giving the frontend a numbered, replayable move history.
