# SimulationAlreadyRunningException

Thrown when `POST /sessions/{sessionId}/simulate` is called for a session that already has a simulation in `IN_PROGRESS` status — the "UI double-click" case called out in the root CLAUDE.md. Extends the shared `ConflictException`, so the controller advice turns it into HTTP 409 with `code=SIMULATION_ALREADY_RUNNING`.

## Key Components

- `SimulationAlreadyRunningException(String sessionId)` - Builds the exception with `ErrorCode.SIMULATION_ALREADY_RUNNING` and a message naming the session, for both the pre-check (`existsBySessionIdAndStatus`) and the race-losing path (unique partial index violation on insert) in `SimulationStarter`.

## Usage Example

```java
if (simulationRepository.existsBySessionIdAndStatus(sessionUuid, GameState.IN_PROGRESS)) {
    throw new SimulationAlreadyRunningException(sessionId);
}
```

Guards `SimulationStarter.start` against starting a second concurrent simulation for the same session, whether caught by the read-check or by the database's unique constraint when two requests race.
