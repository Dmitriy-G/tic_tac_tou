# SimulationStarter

Validates and kicks off a simulation run for `POST /sessions/{sessionId}/simulate`, handling the
409 conflict cases (unknown session, already-running simulation, a completed session being
re-simulated, and the concurrent-double-click race — now all the same case) before handing
execution off to `SimulationRunner` on a virtual thread.

## Key Components

- `@Component` - Registers the class as a Spring bean.
- `SimulationStarter(SessionJpaRepository, SimulationRunner)` - Constructor injection of both collaborators; no `SimulationJpaRepository` or `SessionStateStore` — the session row is the only thing left to check or claim.
- `start(String sessionId)` - Parses `sessionId` via `SessionIdUtils.toUuid` (400 `INVALID_SESSION_ID` on a malformed id), validates the session exists (`SessionNotFoundException` otherwise), then attempts `SessionJpaRepository.claimForSimulation` — a single conditional `UPDATE ... WHERE status = 'CREATED'`. A `1` means this call claimed the session; a `0` means someone else already did (or the session was never `CREATED` to begin with), and the pre-claim read of `session.getStatus()` — never re-read after the CAS, only used for the error message — decides which 409 to throw: `SimulationAlreadyRunningException` if it was `IN_PROGRESS`, `SessionAlreadyCompletedException` otherwise. This is strictly stronger than the old three-read-then-insert: there is no window between check and claim for two concurrent callers to both pass.
- Trace id capture - Reads the correlation id from MDC before spawning the thread (MDC doesn't propagate across `Thread.ofVirtual().start()`), falling back to the `sessionId` itself when nothing is in MDC scope (e.g. a test calling `start()` directly, outside a request).

## Usage Example

```java
void simulate(String sessionId) {
    simulationStarter.start(sessionId);
}
```

`SessionService.simulate` is a thin delegate to this class, which does all the validation and
orchestration work behind the `/simulate` endpoint. See
`docs/adr/0004-session-is-the-game.md` for why the guard collapsed to a single CAS.
