# SimulationJpaRepository

Spring Data JPA repository for `SimulationEntity`, backing `session_db.simulations` — the audit trail of `/simulate` run outcomes described in the root CLAUDE.md, one row per run with its status, error count, and start/finish timestamps.

## Key Components

- `@Repository` - Marks the interface as a Spring Data repository bean.
- `JpaRepository<SimulationEntity, UUID>` - Supplies standard CRUD operations (`save`, `findById`, etc.).
- `findBySessionIdOrderByStartedAtDesc(UUID sessionId)` - Returns a session's simulation runs newest-first; supports look-ups of run history for a given session.
- `existsBySessionIdAndStatus(UUID sessionId, GameState status)` - Checks whether a session already has a simulation in a given state, the query `SimulationStarter` uses to reject a second concurrent `/simulate` call with 409.

## Usage Example

```java
if (simulationRepository.existsBySessionIdAndStatus(sessionUuid, GameState.IN_PROGRESS)) {
    throw new SimulationAlreadyRunningException(sessionId);
}
```

`SimulationStarter` uses this check as the first line of defense against concurrent simulations, backed by a unique partial database index as the second line for the race case.
