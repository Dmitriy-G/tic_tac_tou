# SessionJpaRepository

Spring Data JPA repository for `SessionEntity`, the identity/anchor row in `session_db.sessions`. Per the Storage section of the root CLAUDE.md, this table deliberately holds no board or move history — those live only in the in-memory `SessionStateStore` — so this repository's only real job is existence checks and inserts against the session id.

## Key Components

- `@Repository` - Marks the interface as a Spring Data repository bean, eligible for exception translation into Spring's `DataAccessException` hierarchy.
- `JpaRepository<SessionEntity, UUID>` - Supplies `save`, `existsById`, `findById`, etc. with no custom query methods needed beyond what Spring Data generates.

## Usage Example

```java
if (!sessionRepository.existsById(UUID.fromString(sessionId))) {
    throw new SessionNotFoundException(sessionId);
}
```

Used by `SessionService` and `SimulationStarter` to confirm a session id is valid before creating it, reading it, or starting a simulation against it.
