# SessionEntity

JPA entity mapping to the `session_db.sessions` table. Since one session **is** one game
(`sessionId` **is** the engine's `gameId` — see `docs/adr/0004-session-is-the-game.md`), this
table is now the single source of truth for status, board, winner and error info, not just an
identity/anchor row: `GET /sessions/{id}` is built entirely from this entity plus
`SessionMoveEntity`, which is what makes it survive a process restart.

## Key Components

- `@Entity` / `@Table(name = "sessions")` - Maps this class to the `sessions` table in `session_db`.
- `id` - `@Id` field; the session/game UUID, shared with the engine's `gameId` — no `@GeneratedValue`, since the id is assigned by the session service when it creates the session, not by the database.
- `ownerTokenHash` - SHA-256 hash of the session's owner token (V4 migration); the raw token is never persisted.
- `status` - `@Enumerated(STRING)` `GameState`; `CREATED` at creation, `IN_PROGRESS` once `SessionJpaRepository.claimForSimulation` wins the compare-and-swap, then a terminal value.
- `board` - The current 9-character board string, the engine's authoritative board copied in after every move — never computed locally.
- `winner` - The winning `Symbol` (`X`/`O`), or `null` if the game hasn't ended in a win.
- `errorsCount` - Running count of rejected/erroring steps during the simulation.
- `errorCode` / `errorMessage` - Populated when `status` is `FAILED`.
- `startedAt` / `finishedAt` - Set by `claimForSimulation` and by `SessionStateWriter` respectively; both nullable since a `CREATED` session has neither.
- Getter/setter pairs for every field - entities are mapped explicitly in the repository layer rather than exposed as domain objects, per the project's convention of keeping JPA entities private to `repository/`/`entity/`.

## Usage Example

```java
SessionEntity entity = new SessionEntity();
entity.setId(sessionId);
entity.setStatus(GameState.CREATED);
entity.setBoard(BoardUtils.convertToString(BoardUtils.emptyBoard()));
sessionJpaRepository.save(entity);
```

Persists the full initial state for a newly created session; `SessionStateWriter` and
`SessionJpaRepository.claimForSimulation` update it in place as the simulation progresses, and
`SessionMoveEntity` rows reference it via the composite `(session_id, move_number)` key.
