# SessionEntity

JPA entity mapping to the `session_db.sessions` table. Deliberately an identity/anchor row only — since `sessionId` **is** the engine's `gameId`, no separate id-generation column is needed, and per the project's storage rules the board and move history are never duplicated here; that live, mutable state is held in an in-memory guarded store while a simulation runs, not in this table. This entity exists purely so a session has a durable row to foreign-key `session_db.simulations` against.

## Key Components

- `@Entity` / `@Table(name = "sessions")` - Maps this class to the `sessions` table in `session_db`.
- `id` - `@Id` field; the session/game UUID, shared with the engine's `gameId` — no `@GeneratedValue`, since the id is assigned by the session service when it creates the session, not by the database.
- `getId()` / `setId(UUID)` - Plain accessor pair; entities are mapped explicitly in the repository layer rather than exposed as domain objects, per the project's convention of keeping JPA entities private to `repository/`/`entity/`.

## Usage Example

```java
SessionEntity entity = new SessionEntity();
entity.setId(sessionId);
sessionJpaRepository.save(entity);
```

Persists the anchor row for a newly created session before any simulation runs, so `SimulationEntity` rows can later reference it via the `session_id` foreign key.
