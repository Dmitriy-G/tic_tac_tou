# SessionMoveEntity

JPA entity mapping to the `session_db.session_moves` table — the durable move history, one row
per accepted move. Only successful (`CORRECT_STEP`) moves are persisted here; a rejected attempt
still advances `SessionEntity.errorsCount` but never gets a row, since the composite primary key
`(session_id, move_number)` relies on `move_number` only ever advancing on a real move — a
duplicate would be a bug caught as a constraint violation, not a case this entity is designed to
absorb.

## Key Components

- `@Entity` / `@Table(name = "session_moves")` - Maps this class to the `session_moves` table in `session_db`.
- `id` - `@EmbeddedId` of type `SessionMoveId`, the composite `(sessionId, moveNumber)` natural key.
- `symbol` - `@Enumerated(STRING)` `Symbol` (`X`/`O`) that made this move.
- `position` - The board cell played, `0..8`, stored as `short` to match the migration's `SMALLINT` column exactly.
- `stepStatus` - `@Enumerated(STRING)` `StepStatus` for this move — always `CORRECT_STEP` in practice, since only correct steps are ever inserted.
- `createdAt` - When the move was persisted.
- Getter/setter pairs for every field - entities stay private to `repository/`/`entity/`, mapped to the `MoveRecord` DTO by `SessionMoveMapper`.

## Usage Example

```java
SessionMoveEntity move = new SessionMoveEntity();
move.setId(new SessionMoveId(sessionId, (short) moveNumber));
move.setSymbol(Symbol.X);
move.setPosition((short) 4);
move.setStepStatus(StepStatus.CORRECT_STEP);
move.setCreatedAt(Instant.now());
moveRepository.save(move);
```

`SessionStateWriter.recordMove` inserts one of these per accepted move, alongside the matching
update to `SessionEntity`'s board/status/errorsCount.
