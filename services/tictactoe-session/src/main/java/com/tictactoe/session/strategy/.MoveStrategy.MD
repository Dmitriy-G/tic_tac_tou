# MoveStrategy

The pluggable move-selection contract used by the simulation loop to pick where the automated player moves next. Implementations are resolved per symbol via `MoveStrategyResolver`, so X and O can use different strategies in the same game.

## Key Components

- `selectMove(List<String> board, String symbol)` - Given the current board (9 cells, row-major) and the symbol about to move, returns the chosen cell index (`0..8`). Implementations must never pick an occupied cell.

## Usage Example

```java
MoveStrategy strategy = moveStrategyResolver.resolve(symbol);
int position = strategy.selectMove(progress.board(), symbol);
```

`SimulationStep.execute` resolves the strategy for the current symbol and asks it for the next move before sending it to the engine.
