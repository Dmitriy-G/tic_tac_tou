# EngineUnavailableException

Thrown by `GameEngineClientImpl.classify` when the engine is unreachable (`ResourceAccessException` — connect/read timeout, connection refused) or returns a server error (`HttpServerErrorException`, 5xx). Extends `ServiceUnavailableException`, surfacing as a 503 to callers of the session API, matching the "engine unreachable / circuit open" case in the project's status-code contract. Retryable: a move is idempotent per `(gameId, symbol, position)`, so `GameEngineClientImpl`'s Resilience4j `Retry` is configured to retry exactly this exception type, and retrying after it can never double-apply a move.

## Key Components

- `EngineUnavailableException(ErrorCode errorCode, String message)` - Constructs the exception with a wire-visible error code and a human-readable message, no cause.
- `EngineUnavailableException(ErrorCode errorCode, String message, Throwable cause)` - Same, but chains the originating transport or server-error exception.

## Usage Example

```java
if (e instanceof ResourceAccessException) {
    return new EngineUnavailableException(ErrorCode.ENGINE_UNAVAILABLE,
            "Engine unreachable for game " + gameId, e);
}
```

Raised from `GameEngineClientImpl.classify` on connection failures; the retry predicate `retryOnException(e -> e instanceof EngineUnavailableException)` re-drives the same HTTP call with exponential backoff before giving up.
