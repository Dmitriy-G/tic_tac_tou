# EngineStateLostException

Thrown by `GameEngineClientImpl.classify` when the engine returns 404 for a `gameId` the session service believes exists. Since the session service never keeps its own copy of the board and treats the engine as authoritative, a 404 here means the session's record of the game has gone stale on the engine side (e.g. the engine's database was reset) — not that the original caller of the session API sent a bad request. Extends `BaseException` with its own `ErrorCode`/HTTP status. Terminal: never retried, since the game will not reappear on the engine by retrying.

## Key Components

- `EngineStateLostException(ErrorCode errorCode, String message)` - Constructs the exception with a wire-visible error code and a human-readable message, no cause.
- `EngineStateLostException(ErrorCode errorCode, String message, Throwable cause)` - Same, but chains the originating `HttpClientErrorException.NotFound` from the engine call.

## Usage Example

```java
if (e instanceof HttpClientErrorException.NotFound) {
    return new EngineStateLostException(ErrorCode.ENGINE_STATE_LOST,
            "Engine has no record of game " + gameId, e);
}
```

Raised from `GameEngineClientImpl.classify` when the engine's response is a 404; `BaseGlobalExceptionHandler` maps it to `ENGINE_STATE_LOST` in the session service's error response, and the simulation loop treats it as a fatal, non-retryable failure that terminates the session.
