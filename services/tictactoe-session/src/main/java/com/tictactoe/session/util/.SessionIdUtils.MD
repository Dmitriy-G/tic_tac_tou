# SessionIdUtils

Shared `sessionId` parsing guard for the session module, mirroring the engine's `GameStore.toUuid`. `sessionId` **is** `gameId`, but the session service has its own entry points (`GET /sessions/{id}`, `/simulate`) that need the same "malformed id → 400, not 500" behavior the engine already has for `gameId`.

## Key Components

- `toUuid(String sessionId)` - Wraps `UUID.fromString`; on `IllegalArgumentException` (a non-UUID path variable), throws `BadRequestException(ErrorCode.INVALID_SESSION_ID, ...)` instead of letting the raw exception propagate to a `500 INTERNAL_ERROR`.
- Private constructor - Static-only utility class, never instantiated.

## Usage Example

```java
UUID sessionUuid = SessionIdUtils.toUuid(sessionId);
```

Used by `SessionService.getSession`, `SessionService.simulate`, and `SimulationStarter.start` — every entry point that previously called `UUID.fromString(sessionId)` bare and let a malformed id fall through to a 500.
