# RuleBasedMoveStrategy

The `ADVANCED` `MoveStrategy` implementation, intended to follow the win > block > center > corner > side priority order described in the root CLAUDE.md for a smarter automated player than `RandomMoveStrategy`'s uniform pick.

## Key Components

- `selectMove(List<String> board, String symbol)` - Currently throws `UnsupportedOperationException("Not implemented yet")`; the win/block/center/corner/side rule logic has not been implemented in this class yet, so selecting the `ADVANCED` strategy via `MoveStrategyResolver` will fail at move-selection time rather than at startup.

## Usage Example

```java
case "ADVANCED" -> new RuleBasedMoveStrategy();
```

`MoveStrategyResolver.createStrategy` wires this in for symbols configured with the `ADVANCED` strategy type; until the selection logic is implemented, using `ADVANCED` for either symbol will fail the first time that symbol needs to move.
