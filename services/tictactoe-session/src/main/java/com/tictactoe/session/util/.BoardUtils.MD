# BoardUtils

Small shared constant holder for the session module's board representation, mirroring the engine's own empty-cell convention.

## Key Components

- `EMPTY_CELL` - The `"."` marker used throughout the session module (`SessionStateStore.LiveState.initial()`, `RandomMoveStrategy.selectMove`) to represent an unoccupied board cell, matching the wire representation returned by the engine.

## Usage Example

```java
if (BoardUtils.EMPTY_CELL.equals(board.get(i))) {
    emptyCells.add(i);
}
```

`RandomMoveStrategy` uses the constant to find candidate cells, and `SessionStateStore` uses it to build the initial nine-cell empty board for a freshly created session.
