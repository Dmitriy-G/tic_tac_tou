# BoardUtils

Board representation helpers for the session module, mirroring the engine's own conventions —
now doing real conversion work since `SessionEntity.board` stores the 9-character string form
that `SessionService`/`SessionStateWriter` convert to and from the `List<String>` form used
everywhere else.

## Key Components

- `EMPTY_CELL` - The `"."` marker used throughout the session module (`RandomMoveStrategy.selectMove`, a fresh session's board) to represent an unoccupied board cell, matching the wire representation returned by the engine.
- `BOARD_SIZE` - `9`, the fixed board length.
- `convertToString(List<String> board)` - Joins the 9-cell list into the stored/wire string form.
- `convertToList(String board)` - Splits the stored string back into a 9-element `List<String>`.
- `emptyBoard()` - Returns a fresh nine-`EMPTY_CELL` board, used when a session is created.

## Usage Example

```java
session.setBoard(BoardUtils.convertToString(BoardUtils.emptyBoard()));
...
List<String> board = BoardUtils.convertToList(session.getBoard());
```

`RandomMoveStrategy` uses `EMPTY_CELL` to find candidate cells; `SessionService` and
`SessionStateWriter` use the conversion methods to move between `SessionEntity.board`'s stored
string and the `List<String>` shape the rest of the service works with.
