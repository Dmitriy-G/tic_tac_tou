# SessionApplication

Spring Boot entry point for the Game Session Service. Bootstraps the application context, enables Spring's scheduling infrastructure, and declares the OpenAPI metadata used to generate the service's API documentation.

## Key Components

- `@SpringBootApplication` - Enables auto-configuration, component scanning, and configuration for the session service.
- `@EnableScheduling` - Activates Spring's `@Scheduled` support, used elsewhere in the service for background/periodic work (e.g. simulation orchestration housekeeping).
- `@OpenAPIDefinition` - Declares OpenAPI metadata (title, description, version) used by springdoc to generate the Swagger UI.
- `main(String[] args)` - Standard Spring Boot bootstrap method; starts the embedded server via `SpringApplication.run`.

## Usage Example

```bash
mvn spring-boot:run -pl services/tictactoe-session
```

Starts the Game Session Service on port 8082, exposing the `/sessions` REST API and orchestrating automated games against the Game Engine Service.
