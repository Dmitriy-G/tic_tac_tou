# RandomMoveStrategy

A `MoveStrategy` implementation that picks uniformly at random among the currently empty cells. The simplest of the two strategies referenced in the root CLAUDE.md (`SIMPLE` vs `ADVANCED` in `MoveStrategyResolver`'s config).

## Key Components

- `random` - An injected `Random` instance; per the CLAUDE.md anti-pattern list, this is never `new Random()` inline, so tests can supply a seeded instance for deterministic assertions.
- `RandomMoveStrategy(Random random)` - Constructor injection of the random source.
- `selectMove(List<String> board, String symbol)` - Scans the board for cells equal to `BoardUtils.EMPTY_CELL`, collects their indices, and returns one chosen uniformly at random via `random.nextInt(emptyCells.size())`. Throws `IllegalStateException` if no empty cells remain — a caller error since `SimulationProgress.hasNextIteration()` should prevent this from being reached on a full board, but it fails loudly rather than silently instead of being treated as a normal empty-board loop exit.

## Usage Example

```java
MoveStrategy strategy = new RandomMoveStrategy(new Random(42));
int position = strategy.selectMove(board, "X");
```

Wired by `MoveStrategyResolver` for the `SIMPLE` strategy type; tests construct it directly with a seeded `Random` for deterministic move sequences.
