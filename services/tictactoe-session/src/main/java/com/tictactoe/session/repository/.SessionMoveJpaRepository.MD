# SessionMoveJpaRepository

Spring Data JPA repository for `SessionMoveEntity`, backing `session_db.session_moves` — the
durable, per-move history that used to live only in the now-deleted in-memory `SessionStateStore`.

## Key Components

- `@Repository` - Marks the interface as a Spring Data repository bean.
- `JpaRepository<SessionMoveEntity, SessionMoveId>` - Supplies `save`, `findById`, etc. keyed by the composite `(sessionId, moveNumber)` id.
- `findBySessionIdOrderByMoveNumber(UUID sessionId)` - An explicit `@Query`, not Spring Data's derived-query naming, because the property lives inside the `@EmbeddedId` (`m.id.sessionId`/`m.id.moveNumber`) rather than directly on the entity.

## Usage Example

```java
List<SessionMoveEntity> moves = moveRepository.findBySessionIdOrderByMoveNumber(sessionId);
```

`SessionService.toResponse` maps the result through `SessionMoveMapper::toRecord` to build
`SessionResponse.moves` — the same query a fresh process runs after a restart, since nothing about
move history is held in memory anymore.
