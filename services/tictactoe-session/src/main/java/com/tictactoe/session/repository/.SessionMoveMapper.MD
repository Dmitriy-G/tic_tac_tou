# SessionMoveMapper

Plain static mapper from the persistence-layer `SessionMoveEntity` to the `MoveRecord` DTO,
keeping the JPA entity from leaking into `SessionService`/`SessionResponse`, per the project's
"map explicitly, don't leak domain types" convention.

## Key Components

- `toRecord(SessionMoveEntity entity)` - Builds a `MoveRecord(moveNumber, symbol, position, stepStatus)` from the entity's embedded id and fields.

## Usage Example

```java
List<MoveRecord> moves = moveRepository.findBySessionIdOrderByMoveNumber(sessionId)
        .stream().map(SessionMoveMapper::toRecord).toList();
```

Used once, in `SessionService.toResponse`, to build the `moves` list of every `SessionResponse`.
