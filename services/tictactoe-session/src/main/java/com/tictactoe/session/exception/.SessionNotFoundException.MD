# SessionNotFoundException

Thrown by the session service when a caller references a `sessionId` that has no matching row in `session_db.sessions` — an unknown-gameId equivalent on the session side. Extends the shared `NotFoundException` from `tictactoe-common`, so it is picked up by the service's `@RestControllerAdvice` and translated into the standard error response with HTTP 404.

## Key Components

- `SessionNotFoundException(String sessionId)` - Builds the exception with `ErrorCode.SESSION_NOT_FOUND` and a message naming the missing session id; the advice layer maps this code to the `code` field of the JSON error body.

## Usage Example

```java
if (!sessionRepository.existsById(UUID.fromString(sessionId))) {
    throw new SessionNotFoundException(sessionId);
}
```

Used by `SessionService.getSession` and `SimulationStarter.start` to fail fast with a 404 before doing any further work on an unknown session.
