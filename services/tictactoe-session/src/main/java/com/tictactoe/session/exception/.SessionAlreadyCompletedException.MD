# SessionAlreadyCompletedException

Thrown when `POST /sessions/{sessionId}/simulate` is called for a session whose most recent simulation already reached a terminal status — a session is single-use, since `sessionId` **is** `gameId` and the engine's game for it is finished. Extends the shared `ConflictException`, so the controller advice turns it into HTTP 409 with `code=SESSION_ALREADY_COMPLETED`.

## Key Components

- `SessionAlreadyCompletedException(String sessionId)` - Builds the exception with `ErrorCode.SESSION_ALREADY_COMPLETED` and a message naming the session.

## Usage Example

```java
List<SimulationEntity> previousRuns = simulationRepository.findBySessionIdOrderByStartedAtDesc(sessionUuid);
if (!previousRuns.isEmpty() && previousRuns.get(0).getStatus() != GameState.IN_PROGRESS) {
    throw new SessionAlreadyCompletedException(sessionId);
}
```

Guards `SimulationStarter.start`, checked right after the `IN_PROGRESS` conflict check: without it, a second `/simulate` call on a finished session would mint a fresh engine game and silently reset `SessionStateStore`, discarding the previous run's board, moves, and winner.
