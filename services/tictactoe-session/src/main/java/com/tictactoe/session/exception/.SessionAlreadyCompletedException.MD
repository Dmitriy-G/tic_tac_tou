# SessionAlreadyCompletedException

Thrown when `POST /sessions/{sessionId}/simulate` is called for a session whose status is already
terminal (`X_WON`/`O_WON`/`DRAW`/`FAILED`) — a session is single-use, since `sessionId` **is**
`gameId` and one session is one game. Extends the shared `ConflictException`, so the controller
advice turns it into HTTP 409 with `code=SESSION_ALREADY_COMPLETED`.

## Key Components

- `SessionAlreadyCompletedException(String sessionId)` - Builds the exception with `ErrorCode.SESSION_ALREADY_COMPLETED` and a message naming the session.

## Usage Example

```java
if (sessionRepository.claimForSimulation(id, Instant.now()) == 0) {
    throw session.getStatus() == GameState.IN_PROGRESS
            ? new SimulationAlreadyRunningException(sessionId)
            : new SessionAlreadyCompletedException(sessionId);
}
```

Thrown by `SimulationStarter.start` when the compare-and-swap loses and the pre-claim read shows
the session was already in a terminal state rather than `IN_PROGRESS` — a second `/simulate` call
on a finished session is rejected outright rather than minting a fresh engine game over it.
