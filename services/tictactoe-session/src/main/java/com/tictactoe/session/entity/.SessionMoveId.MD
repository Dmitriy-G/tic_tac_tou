# SessionMoveId

The composite primary key for `SessionMoveEntity`: `(sessionId, moveNumber)`. Implemented as a
Java record annotated `@Embeddable`, per Hibernate 6's native record-embeddable support, rather
than an `@IdClass` — a record keeps the key's two fields declared once instead of scattered across
both the entity and a separate id class.

## Key Components

- `sessionId` - The owning session's UUID, matching `SessionEntity.id`.
- `moveNumber` - 1-based move index within the game, `short` to match the migration's `SMALLINT` column.
- `implements Serializable` - Required by the JPA spec for composite id classes.

## Usage Example

```java
SessionMoveId id = new SessionMoveId(sessionId, (short) 1);
```

Used as `SessionMoveEntity.id` and as the key type for `SessionMoveJpaRepository`; a record gets
`equals`/`hashCode` for free, which Hibernate needs to compare composite keys correctly.
