# EngineContractViolationException

Thrown by `GameEngineClientImpl.classify` when the engine rejects a request with a 4xx status other than 404. Because the engine is the sole authority on game rules and the session service is expected to only send well-formed, in-turn requests, a non-404 4xx means the session service itself built an invalid request — a bug in this service, not a fault the caller of the session API can be blamed for. Extends `InternalException`, so it is reported to session-service clients as a 500 rather than passing the engine's original 4xx through. Terminal: never retried, since resending the same malformed request just reproduces the same 4xx.

## Key Components

- `EngineContractViolationException(ErrorCode errorCode, String message)` - Constructs the exception with a wire-visible error code and a human-readable message, no cause.
- `EngineContractViolationException(ErrorCode errorCode, String message, Throwable cause)` - Same, but chains the originating `HttpClientErrorException` from the engine call.

## Usage Example

```java
if (e instanceof HttpClientErrorException) {
    return new EngineContractViolationException(ErrorCode.ENGINE_CONTRACT_VIOLATION,
            "Session service sent an invalid request to the engine for game " + gameId, e);
}
```

Raised from `GameEngineClientImpl.classify` for any `HttpClientErrorException` that isn't a 404; `BaseGlobalExceptionHandler` maps it to `ENGINE_CONTRACT_VIOLATION` (500) in the session service's error response.
