# EngineBadResponseException

Thrown by `GameEngineClientImpl` when the engine's HTTP response couldn't be parsed or was otherwise unusable — a missing body, a null board on game creation, or any transport/status combination that `classify` can't map to a more specific failure. It signals that the wire contract between the two services is broken, as opposed to a transient outage or a stale session record. Extends `BaseException` (not `InternalException` or `ServiceUnavailableException`), so it carries its own `ErrorCode`/HTTP status rather than being forced into one of those subclasses' fixed status codes. Terminal: `GameEngineClientImpl`'s retry predicate only retries `EngineUnavailableException`, so this exception is never retried.

## Key Components

- `EngineBadResponseException(ErrorCode errorCode, String message)` - Constructs the exception with a wire-visible error code and a human-readable message, no cause.
- `EngineBadResponseException(ErrorCode errorCode, String message, Throwable cause)` - Same, but chains the underlying parsing/transport failure for diagnostics.

## Usage Example

```java
if (response == null || response.board() == null) {
    throw new EngineBadResponseException(ErrorCode.ENGINE_BAD_RESPONSE,
            "Engine returned an incomplete response for game creation: " + gameId);
}
```

Raised in `GameEngineClientImpl.doCreateGame` when the engine's 2xx response is structurally incomplete; `BaseGlobalExceptionHandler` maps it to the `ENGINE_BAD_RESPONSE` error code and its associated HTTP status.
