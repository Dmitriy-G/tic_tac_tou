# SimulationStep

Executes a single move within a simulation run: resolves the right `MoveStrategy` for the symbol whose turn it is, asks it for a position, sends the move to the engine, publishes the result, and updates the run's progress.

## Key Components

- `@Component` - Registers the class as a Spring bean.
- `SimulationStep(GameEngineClient, MoveStrategyResolver, SimulationEventPublisher)` - Constructor injection of the engine client, the per-symbol strategy resolver, and the event publisher.
- `execute(String sessionId, String simulationId, SimulationProgress progress)` - Determines the current symbol from `progress.currentSymbol()`, resolves its `MoveStrategy` via `MoveStrategyResolver`, selects a position, calls `gameEngineClient.move(...)`, publishes the move event, logs it at INFO with move number/symbol/position/status (per the Observability requirement in the root CLAUDE.md), and finally calls `progress.recordStep(response)` to advance the run state.

## Usage Example

```java
while (progress.hasNextIteration()) {
    step.execute(sessionId, simulationId, progress);
    stateWriter.persist(simulationId, progress);
}
```

`SimulationRunner`'s main loop calls `execute` once per iteration; each call is one full move — select, send to the engine, publish, log, record.
