# InternalException

Fault exception thrown for unexpected, server-side failures that don't fit a more specific category (e.g. engine contract violations, simulation timeouts). Extends `BaseException`, so it carries an `ErrorCode` (typically mapping to HTTP 500) that `BaseGlobalExceptionHandler` converts into the standard `ErrorResponse` body.

## Key Components

- `InternalException(ErrorCode errorCode, String message)` - Constructs the exception with a wire error code and a human-readable message.
- `InternalException(ErrorCode errorCode, String message, Throwable cause)` - Same, but preserves the original cause.

## Usage Example

```java
throw new InternalException(ErrorCode.ENGINE_CONTRACT_VIOLATION, "Engine returned an unparseable board string");
```

Thrown by the session service's engine client when a response from the engine can't be safely interpreted, rather than letting a `NullPointerException` propagate to the caller.
