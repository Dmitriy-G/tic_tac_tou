# GameState

Enum representing the lifecycle status of a game/session in this codebase. It is shared between the engine (as the authoritative game outcome) and the session service (as the session's terminal/non-terminal status), per the `tictactoe-common` wire contract.

## Key Components

- `CREATED` - The session/game has been created but simulation has not started yet.
- `IN_PROGRESS` - Moves are being played; the game has not reached a terminal outcome.
- `X_WON` - X completed a winning line; terminal state.
- `O_WON` - O completed a winning line; terminal state.
- `DRAW` - The board is full with no winning line; terminal state.
- `FAILED` - The simulation exited abnormally (e.g. exception, unreachable engine); terminal state, session-service specific.
- `CANCELLED` - The simulation was cancelled via `/sessions/{id}/cancel`; terminal state, session-service specific.

## Usage Example

```java
GameResponse response = new GameResponse(board, GameState.X_WON);
if (response.state() == GameState.IN_PROGRESS) {
    // continue simulating moves
}
```

The engine returns `GameState` as part of `GameResponse`/`MoveResponse` so the session service can decide whether to keep playing or stop.
