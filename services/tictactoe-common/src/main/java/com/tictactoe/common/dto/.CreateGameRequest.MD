# CreateGameRequest

Wire DTO for the request body of `POST /games`. Carries an optional client-supplied game identifier so the caller (the session service) can align a game's id with its own session id, since `sessionId` **is** `gameId` per the API contract.

## Key Components

- `gameId` - `String` record component; the identifier the caller wants the new game to use. May be `null`, in which case the engine generates one.

## Usage Example

```java
CreateGameRequest request = new CreateGameRequest(sessionId.toString());
CreateGameResponse response = engineClient.createGame(request);
```

The session service passes its own session id as the game id so the two services stay aligned on a single identifier for the same game.
