# Symbol

Enum representing the two players in Tic Tac Toe. Used throughout both the engine and session services wherever a move, board cell, or winner needs to be identified by player.

## Key Components

- `X` - The first player; per the domain rules, X always moves first.
- `O` - The second player.

## Usage Example

```java
MoveRequest request = new MoveRequest(Symbol.X, 4);
```

Constructs a move request for X to play the center cell (index 4); the engine validates the symbol and turn order before applying it.
