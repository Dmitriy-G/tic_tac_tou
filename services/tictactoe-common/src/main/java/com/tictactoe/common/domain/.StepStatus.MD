# StepStatus

Enum describing the outcome of a single move attempt against the engine. Unlike faults (which flow through `BaseException`/`ErrorResponse` on non-2xx statuses), `StepStatus` values ride along on the normal HTTP-200 `MoveResponse` — a rejected move is a rule outcome, not a server error.

## Key Components

- `CORRECT_STEP` - The move was legal and applied to the board.
- `GAME_FINISHED` - The move was attempted after the game already reached a terminal state.
- `INVALID_SYMBOL` - The symbol in the move request is not `X` or `O`, or it isn't that symbol's turn is handled separately by `OUT_OF_TURN`.
- `INVALID_POSITION` - The requested position is outside the valid `0..8` range.
- `CELL_OCCUPIED` - The requested cell already holds a symbol.
- `OUT_OF_TURN` - The move was submitted by the symbol that is not next to move.

## Usage Example

```java
MoveResponse response = engineClient.move(gameId, symbol, position);
if (response.stepStatus() != StepStatus.CORRECT_STEP) {
    // pick a different cell and retry, per the session's move-generation strategy
}
```

The session service inspects `stepStatus` after every move attempt to decide whether to advance the simulation or retry with a different cell.
