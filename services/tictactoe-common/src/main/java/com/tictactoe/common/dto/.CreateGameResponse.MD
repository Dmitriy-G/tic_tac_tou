# CreateGameResponse

Wire DTO returned by `POST /games`. Represents the freshly created board as a list of per-cell strings.

## Key Components

- `board` - `List<String>` record component; the initial board state, one entry per cell (empty cells typically represented as `"_"` or similar, per the engine's board encoding).

## Usage Example

```java
CreateGameResponse response = engineClient.createGame(request);
List<String> initialBoard = response.board();
```

The session service reads the freshly created board to initialize its own view of a new game before the first move is played.
