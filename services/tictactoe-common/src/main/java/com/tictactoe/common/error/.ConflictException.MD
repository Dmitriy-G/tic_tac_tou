# ConflictException

Fault exception thrown when a request conflicts with the current state of a resource (e.g. cell occupied, out-of-turn move, game already finished, simulation already running). Extends `BaseException`, so it carries an `ErrorCode` (typically mapping to HTTP 409) that `BaseGlobalExceptionHandler` converts into the standard `ErrorResponse` body.

## Key Components

- `ConflictException(ErrorCode errorCode, String message)` - Constructs the exception with a wire error code and a human-readable message.
- `ConflictException(ErrorCode errorCode, String message, Throwable cause)` - Same, but preserves the original cause.

## Usage Example

```java
throw new ConflictException(ErrorCode.SIMULATION_ALREADY_RUNNING, "Simulation is already running for this session");
```

Thrown by the session service when `/simulate` is called on a session already `IN_PROGRESS`; `BaseGlobalExceptionHandler` maps it to a 409 `ErrorResponse`.
