# ServiceUnavailableException

Fault exception thrown when a dependency the current request needs is unreachable — most notably the engine service from the session side. Extends `BaseException`, so it carries an `ErrorCode` (typically mapping to HTTP 503) that `BaseGlobalExceptionHandler` converts into the standard `ErrorResponse` body.

## Key Components

- `ServiceUnavailableException(ErrorCode errorCode, String message)` - Constructs the exception with a wire error code and a human-readable message.
- `ServiceUnavailableException(ErrorCode errorCode, String message, Throwable cause)` - Same, but preserves the original cause (e.g. a wrapped connect-timeout exception).

## Usage Example

```java
throw new ServiceUnavailableException(ErrorCode.ENGINE_UNAVAILABLE, "Engine did not respond within the configured timeout", cause);
```

Thrown by the session service when it fails fast on session creation because the engine is unreachable, per the "fail fast with 503, do not create a half-session" rule.
