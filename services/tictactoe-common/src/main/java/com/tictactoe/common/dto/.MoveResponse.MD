# MoveResponse

Wire DTO returned by `POST /games/{gameId}/move`. Always carries the authoritative post-move board plus the outcome of both the move attempt itself and the overall game, so the caller never needs to keep its own copy of the board.

## Key Components

- `board` - `List<String>` record component; the authoritative board after the move attempt (unchanged if the move was rejected).
- `gameState` - `GameState` record component; the game's overall lifecycle status after this move.
- `stepStatus` - `StepStatus` record component; the outcome of this specific move attempt (accepted or the specific rejection reason).
- `winner` - `Symbol` record component; set when `gameState` is `X_WON`/`O_WON`, otherwise `null`.

## Usage Example

```java
MoveResponse response = engineClient.move(gameId, Symbol.X, 4);
if (response.stepStatus() == StepStatus.CORRECT_STEP && response.gameState() == GameState.X_WON) {
    // simulation loop can stop, X has won
}
```

The session service always re-reads `board` from the response rather than mutating a locally cached copy, keeping the engine the sole authority on game state.
