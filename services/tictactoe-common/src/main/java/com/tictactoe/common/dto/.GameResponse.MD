# GameResponse

Wire DTO returned by `GET /games/{gameId}`. Represents the authoritative, current state of a game as a single encoded board string plus its lifecycle status.

## Key Components

- `board` - `String` record component; the 9-character board encoding (`X`/`O`/`_` per cell, row-major), matching the `engine_db.games.board` column format.
- `state` - `GameState` record component; the game's current lifecycle status (`IN_PROGRESS`, `X_WON`, `O_WON`, `DRAW`, etc.).

## Usage Example

```java
GameResponse game = engineClient.getGame(gameId);
if (game.state() == GameState.IN_PROGRESS) {
    // safe to submit another move
}
```

Used by the session service (or any caller) to fetch the engine's authoritative view of a game without duplicating board state locally.
