# ErrorCode

Enum pairing every stable, wire-visible error code used across both services with the HTTP status it maps to. The `code` string is part of the API contract; the enum constant name itself is not serialized.

## Key Components

- `VALIDATION_ERROR` (400) - Request failed bean validation (`@Valid`/`@NotNull`/`@Min`/`@Max`, etc.).
- `MALFORMED_REQUEST` (400) - Request body could not be parsed, or a stray `IllegalArgumentException` was raised.
- `METHOD_NOT_ALLOWED` (405) - Wrong HTTP verb used on a known path.
- `UNSUPPORTED_MEDIA_TYPE` (415) - Unsupported `Content-Type` header.
- `INTERNAL_ERROR` (500) - Unexpected server-side failure.
- `GAME_NOT_FOUND` (404) - Engine: unknown `gameId`.
- `INVALID_GAME_ID` (400) - Engine: malformed `gameId`.
- `SESSION_NOT_FOUND` (404) - Session: unknown `sessionId`.
- `INVALID_SESSION_ID` (400) - Session: malformed `sessionId`, thrown by `SessionService.toUuid` mirroring the engine's `GameStore.toUuid`.
- `SIMULATION_ALREADY_RUNNING` (409) - Session: `/simulate` called while a simulation is already `IN_PROGRESS`.
- `SESSION_ALREADY_COMPLETED` (409) - Session: `/simulate` called on a session that already has a terminal simulation.
- `ENGINE_UNAVAILABLE` (503) - Session: engine unreachable or circuit open.
- `ENGINE_STATE_LOST` (502) - Session: engine response left the session unable to determine authoritative state.
- `ENGINE_CONTRACT_VIOLATION` (500) - Session: engine response violated the expected wire contract.
- `ENGINE_BAD_RESPONSE` (502) - Session: engine returned a malformed/unexpected response.
- `DATABASE_ERROR` (503) - Either service: a `DataAccessException` occurred.
- `code` - `private final String` field; the stable string sent on the wire in `ErrorResponse.code`.
- `httpStatus` - `private final int` field; the numeric HTTP status this code maps to.
- `getCode()` - Returns the wire-visible code string.
- `getHttpStatus()` - Returns the numeric HTTP status.
- `toHttpStatus()` - Converts `httpStatus` to a Spring `HttpStatus` for use in a `ResponseEntity`.

## Usage Example

```java
throw new NotFoundException(ErrorCode.GAME_NOT_FOUND, "Game " + gameId + " does not exist");
```

`BaseGlobalExceptionHandler` reads `ErrorCode.GAME_NOT_FOUND.toHttpStatus()` (404) and `.getCode()` (`"GAME_NOT_FOUND"`) to build the `ResponseEntity<ErrorResponse>` returned to the client.
