# BaseException

Abstract base type for every fault raised by either service (as opposed to a rule outcome like `StepStatus`, which travels on the normal HTTP-200 channel). Carries the `ErrorCode` that `BaseGlobalExceptionHandler` maps to an HTTP status and wire error code.

## Key Components

- `errorCode` - `private final ErrorCode` field; the stable, wire-visible code identifying the fault, set at construction and never reassigned.
- `BaseException(ErrorCode errorCode, String message)` - Protected constructor for subclasses raising a fault without an underlying cause.
- `BaseException(ErrorCode errorCode, String message, Throwable cause)` - Protected constructor for subclasses wrapping an underlying cause.
- `getErrorCode()` - Returns the `ErrorCode` so `BaseGlobalExceptionHandler` can look up the HTTP status and wire code to respond with.

## Usage Example

```java
public class NotFoundException extends BaseException {
    public NotFoundException(ErrorCode errorCode, String message) {
        super(errorCode, message);
    }
}
```

Every concrete fault exception in the codebase (`BadRequestException`, `ConflictException`, `NotFoundException`, etc.) extends `BaseException` so `BaseGlobalExceptionHandler` can handle them uniformly via a single `@ExceptionHandler(BaseException.class)`.
