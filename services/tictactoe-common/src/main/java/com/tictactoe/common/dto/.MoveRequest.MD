# MoveRequest

Wire DTO for the request body of `POST /games/{gameId}/move`. Carries the symbol making the move and the target cell position, with bean-validation constraints enforced before the request reaches the engine's business logic.

## Key Components

- `symbol` - `Symbol` record component, annotated `@NotNull`; must be `X` or `O`.
- `position` - `int` record component, annotated `@Min(0)` `@Max(8)`; the target cell index, `0..8` row-major.

## Usage Example

```java
MoveRequest request = new MoveRequest(Symbol.O, 8);
MoveResponse response = restClient.post().uri("/games/{id}/move", gameId).body(request)...;
```

Bean validation rejects malformed requests (missing symbol, out-of-range position) with a 400 before the engine's move-validation logic ever runs.
