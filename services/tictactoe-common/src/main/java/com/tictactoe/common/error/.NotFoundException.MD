# NotFoundException

Fault exception thrown when a requested resource (game or session) does not exist. Extends `BaseException`, so it carries an `ErrorCode` (typically mapping to HTTP 404) that `BaseGlobalExceptionHandler` converts into the standard `ErrorResponse` body.

## Key Components

- `NotFoundException(ErrorCode errorCode, String message)` - Constructs the exception with a wire error code and a human-readable message.
- `NotFoundException(ErrorCode errorCode, String message, Throwable cause)` - Same, but preserves the original cause.

## Usage Example

```java
throw new NotFoundException(ErrorCode.SESSION_NOT_FOUND, "Session " + sessionId + " does not exist");
```

Thrown by the session service when `GET /sessions/{sessionId}` is called with an unknown id; `BaseGlobalExceptionHandler` maps it to a 404 `ErrorResponse`.
