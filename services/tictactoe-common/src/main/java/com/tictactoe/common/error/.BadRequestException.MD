# BadRequestException

Fault exception thrown for malformed or semantically invalid requests. Extends `BaseException`, so it carries an `ErrorCode` (typically one whose `httpStatus` is 400) that `BaseGlobalExceptionHandler` maps to the standard `ErrorResponse` body.

## Key Components

- `BadRequestException(ErrorCode errorCode, String message)` - Constructs the exception with a wire error code and a human-readable message.
- `BadRequestException(ErrorCode errorCode, String message, Throwable cause)` - Same, but preserves the original cause for logging/stack traces.

## Usage Example

```java
throw new BadRequestException(ErrorCode.INVALID_GAME_ID, "gameId must be a valid UUID");
```

Thrown by service code when a request is well-formed JSON but fails a semantic check; `BaseGlobalExceptionHandler` converts it into a 400 `ErrorResponse` with `code = "INVALID_GAME_ID"`.
