# main

The application entry point. Mounts `App` into `#root`, wrapped in `ErrorBoundary` (so a render throw shows a message instead of a white screen) inside `StrictMode` (so React's development-mode double-invocation surfaces impure effects early).

## Key Components

- `createRoot(document.getElementById('root')!)` - React 19's root API; the non-null assertion is safe because `index.html` always ships the `#root` element this targets.
- `<StrictMode>` - Outermost wrapper; only affects development builds.
- `<ErrorBoundary>` - Wraps `<App />` so an unhandled render error is caught at the top level rather than unmounting the whole page.
- `import './styles/index.css'` - The one global stylesheet import, loaded once here rather than per component.

## Usage Example

```tsx
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <ErrorBoundary>
      <App />
    </ErrorBoundary>
  </StrictMode>,
)
```

This file is the only place `ReactDOM.createRoot` is called; every other module is imported transitively from `App`.
