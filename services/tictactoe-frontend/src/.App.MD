# App

The UI's structural root. Calls the single `useSimulation` hook and renders the pieces around it — status banner, reconnecting/error lines, board, start button, move log. Owns no state of its own; every value it renders comes from the hook's `state`/`isSimulating`/`start`.

## Key Components

- `useSimulation()` - The only hook `App` calls; returns `{ state, isSimulating, start }`, composing SSE, polling fallback, and the simulation reducer.
- `calculateWinner(state.board)` - Derived (via `useMemo`, recomputed only when the board changes) to get the winning line for `Board`'s highlight; the engine remains the outcome authority, this is purely a rendering aid.
- `state.phase === 'reconnecting'` - Renders a "Reconnecting…" line while the SSE stream is down and polling is covering for it.
- `state.phase === 'failed'` - Renders `state.message` in an error line.
- `<button className="start" onClick={start} disabled={isSimulating}>` - The one control in the UI; disabled while a simulation is in flight, per the CLAUDE.md requirement.

## Usage Example

```tsx
// main.tsx
<ErrorBoundary>
  <App />
</ErrorBoundary>
```

`App` is mounted once at the root; everything it displays reacts to the `SimulationState` produced by `useSimulation`.
