# types

The frontend's type vocabulary: board/player primitives plus the two wire shapes mirrored from the session service — `SessionResponse` (the full `GET /sessions/{id}` payload) and `SessionEvent` (one SSE frame). Kept separate from any single component so every layer (`gameApiService`, the reducer, the hooks, the components) imports from the same source.

## Key Components

- `Player = 'X' | 'O'`, `SquareValue = Player | null`, `BoardState = SquareValue[]` - The board's in-memory representation, distinct from the wire format (`string[]` of `'X'`/`'O'`/`'_'`), which `normalizeBoard` converts between.
- `WinResult { winner, line }` - Return type of `calculateWinner`.
- `GameOutcome = 'X_WON' | 'O_WON' | 'DRAW' | 'FAILED'` and `SessionStatus = 'CREATED' | 'IN_PROGRESS' | GameOutcome` - Mirror the session service's `GameState`/session status values from the shared backend contract exactly — there is no `CANCELLED` value here because the backend has no cancel endpoint; `session.cancel()` is not implemented (see the session service's README).
- `StepStatus` - Mirrors the engine's per-move outcome codes (`CORRECT_STEP`, `CELL_OCCUPIED`, `OUT_OF_TURN`, etc.), used to annotate each `MoveHistoryEntry`.
- `MoveHistoryEntry { moveNumber, symbol, position, stepStatus }` - One row of the move log; the same shape both `SessionResponse.moves` and the reducer's derived history use.
- `SessionResponse` - Mirrors the session service's `SessionResponse` — the full session view `GET /sessions/{id}` returns, sufficient on its own to rebuild the UI without the SSE stream (used for rehydration and polling fallback).
- `SessionEvent` - One `update`/`failure` SSE frame; `board` and `stepStatus` are nullable because a `FAILED` event carries neither.
- `ApiErrorBody` - Mirrors the shared `ErrorResponse` both backend services return for a fault; all fields optional since `throwApiError` parses defensively.

## Usage Example

```ts
import type { BoardState, SessionResponse, SessionEvent } from '../utils/types'
```

Every other frontend module (`gameApiService`, `simulationReducer`, the hooks, `logic.ts`, `moveLog.ts`, the components) imports its shapes from here rather than redeclaring them locally.
