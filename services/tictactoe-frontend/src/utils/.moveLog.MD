# moveLog

Formats a single `MoveHistoryEntry` into its display string. Kept as a pure function over the structured record — not a client-observed timestamp or a pre-built string stored in state — so a move replayed from `session.moves` after a reconnect renders identically to one that arrived live over SSE.

## Key Components

- `formatMoveLogEntry(entry: MoveHistoryEntry): string` - Produces `"Move {moveNumber}: {symbol} was set to {position + 1} cell. {stepStatus}"`; `position + 1` converts the 0-indexed board position to the 1-indexed cell number shown to the user.

## Usage Example

```ts
formatMoveLogEntry({ moveNumber: 3, symbol: 'X', position: 4, stepStatus: 'CORRECT_STEP' })
// "Move 3: X was set to 5 cell. CORRECT_STEP"
```

`MoveLog` calls this at render time for every entry in `entries`, rather than storing formatted strings in the reducer state.
