# StatusBanner

The status line at the top of the game, driven entirely by `state.phase` (and, for the terminal `finished` phase, `state.outcome`). A `phase -> text` lookup table plus one small branch, `aria-live="polite"` since nothing else announces the automatic updates to a screen reader.

## Key Components

- `STATUS_TEXT: Record<Exclude<SimulationState['phase'], 'finished'>, string>` - Static copy for every non-terminal-with-outcome phase (`idle`, `starting`, `running`, `reconnecting`, `failed`); `finished` is excluded because its text depends on `outcome`, not just the phase.
- `interface StatusBannerProps { state: SimulationState }` - Takes the whole reducer state rather than individual fields, since the text depends on which discriminated-union variant it is.
- `finished` branch - `DRAW` -> "It's a draw!", `CANCELLED` -> "Simulation cancelled.", otherwise `Winner: X` or `Winner: O` derived from `outcome`.
- `aria-live="polite"` - Lets a screen reader announce status changes without interrupting whatever the user is doing.

## Usage Example

```tsx
<StatusBanner state={state} />
```

`App` passes the full `SimulationState` from `useSimulation` straight through; `StatusBanner` never touches the board or move log.
