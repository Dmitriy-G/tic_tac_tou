# ErrorBoundary

Class component wrapping `<App />` in `main.tsx`. Catches any render-phase throw beneath it and shows a plain error message instead of leaving the user with a white screen — React has no hook equivalent for this, so it has to be a class.

## Key Components

- `static getDerivedStateFromError()` - Flips `hasError` to `true` on the next render after a descendant throws; this is what actually swaps the tree for the fallback UI.
- `componentDidCatch(error, info)` - Side-effect hook for the same event; logs the error and component stack to the console rather than swallowing it silently.
- `render()` - Returns the `role="alert"` fallback message when `hasError`, otherwise renders `this.props.children` unchanged.
- `interface ErrorBoundaryProps { children: ReactNode }` - The only prop; this component is a pure wrapper.

## Usage Example

```tsx
<ErrorBoundary>
  <App />
</ErrorBoundary>
```

Mounted once, directly around `<App />`, in `main.tsx` — the outermost catch point for the whole UI.
