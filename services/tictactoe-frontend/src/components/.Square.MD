# Square

A single presentational board cell, wrapped in `memo` since a board update only ever changes one of nine squares — re-rendering the other eight on every move would be wasted work.

## Key Components

- `interface SquareProps { value: SquareValue; isWinning: boolean }` - `value` is `'X' | 'O' | null`; `isWinning` toggles the highlight class.
- `memo(function Square(...))` - Named function inside `memo` (rather than an anonymous arrow) so it still shows up as `Square` in React DevTools and stack traces.
- `role="gridcell"` - Pairs with `Board`'s `role="grid"`/`role="row"` for the accessible grid structure.
- `aria-label={value ? \`Square: ${value}\` : 'Empty square'}` - Announces cell contents to screen readers, since the visible text alone (`X`, `O`, or nothing) isn't descriptive on its own.

## Usage Example

```tsx
<Square key={index} value={value} isWinning={winningLine?.includes(index) ?? false} />
```

Rendered nine times by `Board`, one per board position; `memo` means only the squares whose `value`/`isWinning` actually changed re-render after a move.
