# Board

Renders the 3x3 grid as a `role="grid"` of 9 `Square`s, grouped into `role="row"` wrappers for assistive tech, and tells each `Square` whether it belongs to the winning line.

## Key Components

- `interface BoardProps { squares: BoardState; winningLine: number[] | null }` - `squares` is the flat 9-cell board; `winningLine` is the three indices to highlight, or `null` before a win.
- `role="grid"` / `role="row"` / `role="gridcell"` (the last on `Square`) - The accessible grid structure the CLAUDE.md testing/UI notes call for.
- `style={{ display: 'contents' }}` on each row `div` - Keeps the row wrappers out of the CSS grid's box model, so the 9 `Square`s stay direct grid items for `.board`'s `grid-template-columns`/`-rows` layout while the DOM still exposes row/cell structure to screen readers.
- `key={index}` - A fixed-length positional array (board positions never reorder), the case where an index key is correct rather than an anti-pattern.
- `winningLine?.includes(index) ?? false` - Per-cell winning-highlight flag passed down to `Square`.

## Usage Example

```tsx
<Board squares={state.board} winningLine={winningLine} />
```

`App` recomputes `winningLine` from `state.board` via `calculateWinner` and passes both straight through; `Board` itself holds no state.
