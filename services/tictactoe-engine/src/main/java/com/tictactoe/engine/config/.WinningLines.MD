# WinningLines

Holds the 8 winning lines of the tic-tac-toe board (3 rows, 3 columns, 2 diagonals), parsed from the `game.winning-lines` configuration property and validated once at application startup. Failing fast here means a malformed property crashes context startup instead of causing a wrong or missing win detection mid-game.

## Key Components

- `@Component` - Registers this as a Spring bean, constructed once at startup from the injected configuration value.
- `LINE_LENGTH` - Constant `3`; every winning line must contain exactly this many cell indices.
- `WinningLines(String config)` - Constructor injected with `${game.winning-lines}`; parses the semicolon/comma-separated string into `int[][]` and validates it immediately.
- `lines()` - Returns the parsed `int[][]` of winning lines for use by `GameOutcomeEvaluator`.
- `parse(String config)` - Splits the config string on `;` for lines and `,` for indices, wrapping any `NumberFormatException` in an `IllegalStateException` with a descriptive message.
- `validate(int[][] lines)` - Ensures at least one line is defined, every line has exactly `LINE_LENGTH` indices, and every index is within `0..BoardUtils.BOARD_SIZE - 1`.

## Usage Example

```yaml
game:
  winning-lines: "0,1,2;3,4,5;6,7,8;0,3,6;1,4,7;2,5,8;0,4,8;2,4,6"
```

At startup, `WinningLines` parses this property into an `int[][]` of 8 lines; `GameOutcomeEvaluator` then iterates `lines()` to check whether any line is fully occupied by the same symbol.
