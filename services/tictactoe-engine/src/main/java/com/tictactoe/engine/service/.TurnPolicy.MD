# TurnPolicy

Decides whose turn it is to move on a given board, enforcing the rule that X always moves first and turns strictly alternate. This is the piece of `MoveValidator` that makes the engine reject out-of-turn moves without trusting the caller.

## Key Components

- `@Component` - Registers this as a Spring bean, injected into `MoveValidator`.
- `isOutOfTurn(List<String> board, Symbol symbol)` - Returns `true` when it is NOT `symbol`'s turn to move. Counts empty cells: an even count means X moves next (X always moves first), an odd count means O moves next. A full board (`emptyCount == 0`) is always treated as out of turn — a defensive branch, since `GameOutcomeEvaluator` prevents a full board from remaining `IN_PROGRESS` in normal operation.

## Usage Example

```java
if (turnPolicy.isOutOfTurn(board, move.symbol())) {
    status = StepStatus.OUT_OF_TURN;
}
```

`MoveValidator.validate` calls this last in its rule chain so an out-of-turn move overrides any other status that may have already been set, per the last-rule-wins precedence documented on `MoveValidator`.
