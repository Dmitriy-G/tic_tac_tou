# EngineApplication

Spring Boot entry point for the Game Engine Service. Bootstraps the application context and declares the OpenAPI metadata used to generate the service's API documentation.

## Key Components

- `@SpringBootApplication` - Enables auto-configuration, component scanning, and configuration for the engine service.
- `@OpenAPIDefinition` - Declares OpenAPI metadata (title, description, version) used by springdoc to generate the Swagger UI.
- `main(String[] args)` - Standard Spring Boot bootstrap method; starts the embedded server via `SpringApplication.run`.

## Usage Example

```bash
mvn spring-boot:run -pl services/tictactoe-engine
```

Starts the Game Engine Service on port 8081, exposing the `/games` REST API.
