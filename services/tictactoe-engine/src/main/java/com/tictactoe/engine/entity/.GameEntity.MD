# GameEntity

JPA entity mapping to the `games` table in `engine_db`. Represents the persisted row for a single game: its id, its board encoded as a 9-character string, and its current state. This entity is private to the `repository` package — it never leaks past `GameStore`/`Game`; domain and DTO code always work with `List<String>` boards and the `GameState` enum, never with this entity directly.

## Key Components

- `@Entity` / `@Table(name = "games")` - Maps this class to the `games` table, whose schema is owned by Flyway (`ddl-auto: validate`).
- `@Id private UUID id` - Primary key; the game id, generated by the caller (or `GameController`) rather than by the database.
- `@Column(name = "board", nullable = false, length = 9)` - The 9-cell board encoded as a single `VARCHAR(9)` string (`X`/`O`/`.` per cell), matching the storage convention described in the project's Storage section.
- `@Column(name = "state", ...)` / `@Enumerated(EnumType.STRING)` - Persists the shared `GameState` enum (`IN_PROGRESS`, `X_WON`, `O_WON`, `DRAW`) as its string name; the winner is derived from this, not stored separately.
- Getters/setters (`getId`/`setId`, `getBoard`/`setBoard`, `getState`/`setState`) - Plain JavaBean accessors used by Hibernate and by `GameStore` when reading/writing rows.

## Usage Example

```java
GameEntity entity = new GameEntity();
entity.setId(UUID.fromString(gameId));
entity.setBoard(BoardUtils.convertToString(board));
entity.setState(GameState.IN_PROGRESS);
gameJpaRepository.save(entity);
```

`GameStore` is the only class that constructs and persists `GameEntity` instances; it wraps them in the package-private `Game` class before exposing anything to `GameService`.
