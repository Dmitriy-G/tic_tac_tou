# GameNotFoundException

Thrown by `GameStore.load` when a requested `gameId` has no matching row in `engine_db.games`. Extends the shared `NotFoundException` (itself a `BaseException`) from `tictactoe-common`, so it is handled automatically by the inherited `handleBaseException` in `GameExceptionHandler` without any engine-specific catch logic — it maps to HTTP `404` with error code `GAME_NOT_FOUND`.

## Key Components

- `GameNotFoundException(String gameId)` - Constructs the exception with `ErrorCode.GAME_NOT_FOUND` and a message identifying the missing game id; the base class resolves the `404` status from the error code.

## Usage Example

```java
GameEntity entity = gameRepository.findById(toUuid(gameId))
        .orElseThrow(() -> new GameNotFoundException(gameId));
```

`GameStore.load` throws this when a game id is well-formed but no row exists; `GameExceptionHandler` turns it into `{"status": 404, "code": "GAME_NOT_FOUND", ...}`.
