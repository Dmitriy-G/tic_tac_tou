# GameJpaRepository

Spring Data JPA repository for `GameEntity`, providing CRUD access to the `games` table in `engine_db`. It adds no custom query methods — the standard `JpaRepository` operations (`findById`, `save`, etc.) are all `GameStore` needs. This interface is private to the `repository` package; nothing outside it should depend on Spring Data directly.

## Key Components

- `@Repository` - Marks this as a Spring Data repository bean, enabling exception translation into Spring's `DataAccessException` hierarchy (handled by the inherited `handleDataAccess` in `BaseGlobalExceptionHandler`).
- `extends JpaRepository<GameEntity, UUID>` - Supplies standard CRUD and paging operations for `GameEntity`, keyed by its `UUID` id.

## Usage Example

```java
GameEntity entity = gameJpaRepository.findById(gameUuid)
        .orElseThrow(() -> new GameNotFoundException(gameId));
gameJpaRepository.save(entity);
```

`GameStore` is the sole caller of this repository, keeping `GameEntity` and Spring Data types out of the rest of the engine service.
