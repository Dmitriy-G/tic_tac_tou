# GameExceptionHandler

The engine service's single `@RestControllerAdvice`, required by the project's error-handling conventions ("one `@RestControllerAdvice` per service"). It has no engine-specific handlers of its own today: `GameNotFoundException` and the `INVALID_GAME_ID` case both extend the shared `BaseException` and are already handled by the inherited `handleBaseException`, and malformed JSON bodies are handled by the inherited `handleMalformedBody` in `BaseGlobalExceptionHandler`. The class exists as the concrete advice bean Spring scans, and as the extension point for any future engine-only exception handling.

## Key Components

- `@RestControllerAdvice` - Registers this class as the global exception-handling bean for the engine service, applied to every `@RestController` (currently only `GameController`).
- `extends BaseGlobalExceptionHandler` - Inherits handlers for `BaseException` (covers `GameNotFoundException`/`GAME_NOT_FOUND` and `INVALID_GAME_ID`), bean-validation failures, malformed request bodies, unsupported methods/media types, database errors, and any unexpected `Exception`, all mapped to the shared `ErrorResponse` shape with `timestamp`, `status`, `code`, `message`, `path`.

## Usage Example

```java
@RestControllerAdvice
public class GameExceptionHandler extends BaseGlobalExceptionHandler {
}
```

A `GameNotFoundException` thrown from `GameStore.load` propagates up through `GameService` and `GameController` uncaught; Spring routes it to the inherited `handleBaseException`, which produces a `404` response with `code: "GAME_NOT_FOUND"`.
