# BoardUtils

Static conversion helpers between the two board representations used across the engine: the `List<String>` form used by domain logic (`MoveValidator`, `TurnPolicy`, `GameOutcomeEvaluator`, `GameService`) and the 9-character `String` form persisted in `engine_db.games.board`. Also the single source of truth for the empty-cell marker and board size constants.

## Key Components

- `EMPTY_CELL` - The `"."` marker used for an unoccupied cell, both in the persisted string and the in-memory list.
- `BOARD_SIZE` - Constant `9`, the total number of cells; used for position-range validation (`MoveValidator`) and winning-line index validation (`WinningLines`).
- `convertToString(List<String> board)` - Joins a `List<String>` board into a single 9-character string for persistence, replacing any `null` entries with `EMPTY_CELL`.
- `convertToList(String board)` - Splits a persisted 9-character string back into a `List<String>` of single-character cell values.
- `emptyBoard()` - Returns a fresh `List<String>` of 9 `EMPTY_CELL` entries, used by `GameService.createGame`.

## Usage Example

```java
List<String> board = BoardUtils.emptyBoard();
gameStore.create(gameId, board);
...
String persisted = BoardUtils.convertToString(board);
List<String> reloaded = BoardUtils.convertToList(persisted);
```

`GameStore` converts to the string form when writing to `GameEntity.board`, and `Game.board()` converts back to the list form for `GameService` to work with.
